# 其他咨询类报告审核要点（估值分析 / 价值分析 / 债权价值分析[非不良] 等咨询类专业文件）

> **特点**：此类报告形式多样、**无单一专门准则文件**。审核以《资产评估基本准则》《资产评估职业道德准则》为底线，**参照公开权威资讯**建立要点（以下三份已全文研读，存于桌面"咨询类审核参考依据"）：①**《监管企业估值报告审核指引》（国资发产权规〔2024〕8号附件·央企估值报告审核指引，25条，最核心审核清单）**；②**上海市国资委《估值报告审核指引（试行）》（沪国资委评估〔2020〕413号，33条全文＋"估值方法选择参考"附件）**；③**北京资产评估协会《资产评估机构出具估值报告注意事项研究》（2024，462份样本统计＋实务高频缺陷＋出具注意事项）**。另：国资发产权规〔2024〕8号（5类可估值情形）、中评协各《资产评估专家指引》（可作咨询类报告参考）、"评估/估值/咨询三类报告定位探讨"综述。债权价值分析叠加 `debt-analysis.md`。
> **交叉验证规则（按本所要求）**：**涉及估值（给出价值数额/区间）的咨询报告，必须做交叉验证**；**不涉及估值（纯定性分析、无价值数额结论）的咨询报告，不做交叉验证分析**。

## 一、报告识别与定位（先分清类别、守住与法定评估的边界）
- **三类报告边界**：资产评估报告（法定评估、强约束）／估值报告（估值咨询）／评估咨询报告·价值分析报告（咨询性质）。三者边界易模糊，审核须先判定本报告属于哪一类、其结论的法律效力与使用场景。
- **⭐红线：咨询类报告不得替代法定资产评估**。涉及国有资产产权变动、且依法（《资产评估法》《企业国有资产评估管理暂行办法》等）必须进行资产评估的经济行为，必须出具资产评估报告，**不得以估值报告/价值分析报告规避法定评估**。审核第一步：核对该业务是否属"依法必须评估"情形——若是而出了咨询报告，属重大合规问题。
- **适用情形**（参照国资发产权规〔2024〕8号）：内部重组整合、对外投资并购的意向/初步决策参考、不涉及产权变动的内部管理与研究、提供价值区间参考等，可出估值/价值分析报告。
- **价值结论形式**：估值结论可为确定值或**区间值**；采用区间值的，应在区间内确定一个**最大可能值并说明确定依据**；须**明确使用有效期**。

## 二、通用审核底线（五原则，《估值报告审核指引》）
- **合规性**：遵守法律法规，依指引及行业准则，合理使用估值假设。
- **独立性**：诚实守信、勤勉尽责、独立分析估算，**不得直接以预先设定的价值作为结论**（迎合委托方预设价值是最严重的执业问题）。
- **专业性**：人员具备相应专业知识与实践经验；机构与人员资质、独立性（与委托方/对象无利害关系）、有委托合同。
- **完整性**：对项目背景、目的、范围、过程充分披露。
- **规范性**：内容完整、表达严谨准确。

## 三、估值报告审核要点（央企《估值报告审核指引》第4–18条逐条核——估值类咨询报告核心清单）
基本要素：**标题、目录、正文、附件**（齐全、文字准确清晰、**能从估值角度提供价值参考和风险提示**，第4条）。
- **标题（第5条）**：采"委托方名称＋经济行为描述＋估值对象＋估值报告"形式。
- **目录（第6条）**：列明正文、附件内容及**页码**。
- **正文（第7条）**应含：估值目的／委托方和被估值对象概况／估值基准日／估值假设和限制条件／价值类型／估值程序实施过程和情况／估值方法／估值结论／特别事项说明／签字盖章。
- **估值目的（第8条）**：清晰说明本次估值服务的**经济行为及其决策或批准情况**（实务高频缺漏：仅约13%披露决策/批准情况）。
- **委托方与被估值对象概况（第9条）**：被估值对象为**企业股权**的，须介绍历史沿革、股权结构、近三年财务及经营状况；存在**重大关联交易**的，须参考/引用其他尽调披露关联方、关联业务、交易方式；单项资产/资产组的，须介绍基本情况、权属、经济及质量状况。
- **基准日（第10条）**：是否接近经济行为/特定事项实施日；基准日后重大影响事项是否调整基准日或在结论/交易条件中考虑。
- **假设和限制条件（第11条）**：是否结合宏观/行业/企业/资产应用场景；**是否背离事实或有颠覆性影响**；未决事项假设是否说明影响。
- **价值类型（第12条）**：列明类型及定义；**市场价值以外的（投资价值/在用价值/清算价值/残余价值等）须说明选取理由合理性**。
- **估值程序（第13条）**：介绍履行方式与内容；对影响结论较大的事项/资料是否调查分析；**未履行与委托方商定程序的，是否披露对结论的影响**（实务最严重缺漏：约53%报告缺"程序实施过程"）。
- **估值方法（第14条）**：是否两种及以上并说明合理性；只用一种须说明其他方法不适用原因/所受限制。
- **估值结论（第15条）**：两种以上方法须说明**结果差异及原因、最终确定结论的理由**。
- **特别事项（第16条）**：结合/引用其他尽调，充分披露对结论影响重大事项的原因、性质、影响及如何考虑；不宜披露的，企业形成专项处理意见。
- **签章规则（第17条）**：盖章/签字须符合所在国家/区域法规（核署名资格与一致性）。**※签字盖章在审核通过、报告出具时才完成，本次审核"缺签字/缺机构章"不作为问题提出（见 SKILL.md 一节）。**
- **附件（第18条）**：经济行为批准文件、核心资产权属证明（如有）、财务资料、委托合同与估值工作相关内容页、营业执照（如有）、**估值机构与人员独立性声明**、其他重要支撑材料（实务高频缺漏：约33%缺附件）。
- 摘要应简明反映经济行为/目的/对象范围/价值类型/基准日/方法/主要假设/重要参数/结论及**使用有效期**/特别事项（上海413号第15条；估值目的应唯一，第17条）。

## 四、估值方法审核要点（央企《审核指引》第19–25条 / 上海413号；仅当涉及估值/价值测算时）
- **方法数量**：原则上**两种及以上**并比较分析；只用一种须披露其他方法不适用原因。⚠**"两种方法"须为不同估值途径**（收益/市场/成本三途径中的两种）——同一途径下两种具体方法（如上市公司比较法＋交易案例比较法、或两种DCF模型）通常**只算一种方法**；且两法须独立估算，**不得相互引用估值结果**（北京研究高频问题）。
- **收益法（第19/20条）**：满足未来收益可合理预测、主要风险可考量、重要参数可计量、收益期限能确定；模型结合资本结构/经营模式/发展阶段/收益情况选择；应形成收入、成本费用、折旧摊销、营运资金、折现率**完整预测表**，条件允许形成资本性支出、非经营性资产负债预测表；主要参数预测与计算依据充分说明。⚠核查：是否直接采用企业预测数据**无分析调整**、亏损转盈利**缺支撑**、未对溢余/非经营性资产负债调整。
- **市场法（第21/22条）**：可比公司/交易案例可获得、与对象可比、差异可修正；价值比率/模型符合行业特点盈利模式；对可比对象与对象的行业/地位/规模/盈利模式/财务数据比对并修正、说明依据；交易案例还须比对交易时间/条件/股比。⚠核查：价值比率选择、可比对象选择、比率调整无说明或不充分。
- **资产基础法（第23/24条）**：表内外资产负债可识别、价值可判断可估算；说明各项重置成本构成要素、充分考虑贬值因素并合理确定各项贬值；主要资产负债选取典型案例描述过程/方法/参数/结论。
- **其他估值方法（第25条）**：与被估值对象匹配，关键参数与估值依据合理。
- **方法选择参考（上海413号附件）**：按企业发展阶段（种子/起步期→资产基础法或最近融资价格调整法；早期发展→收益法＋市场倍数复核；稳定/成熟→收益法＋市场法）；创新领域关键指标——生物医药(管线估值法、P/S、P/Peak sales)、人工智能/集成电路/互联网(DCF、EV/S、EV/EBITDA、P/MAU)、文化创意(收益法/市场法)；境外并购(收益法/市场法，关注会计准则差异、汇率、法律体系、融合成本)。
- 折现率、可比对象选取与可比因素调整过程**可追溯、有据**；多方法结果差异有合理解释；价值结论形成逻辑清晰。

## 五、信息来源与核验（第8/9/20条）
- 应获取资料并了解对象现状、法律权属；对资料**核查验证**，保证真实性、完整性、合法性；
- **无法实施核查的，须说明理由并披露影响程度**；
- 假设应结合企业人力资源、技术水平、经营状况、历史业绩，并考虑宏观经济、行业现状与前景，**有支撑、不悬空**。

## 六、债权价值分析（非不良）专项
- 非金融不良资产的债权价值分析（如一般应收债权、企业间往来债权、投融资债权价值咨询）：方法与不良资产债权分析相通（本金＋利息＋违约金；担保物变现价值；债务人/保证人偿债能力；诉讼时效），但**不套用《金融不良资产评估指导意见》"价值分析业务"的特定口径**（那是金融不良资产专用）。详见 [debt-analysis.md] 方法部分。
- **⭐若送审材料含法律尽职调查报告，则"法律尽调↔价值分析报告匹配程度"仍为最高优先级审核标准**：债权真实性、诉讼时效（超时效债权定价应为零或重大折价）、担保登记效力、债务人/保证人主体一致性、优先受偿冲突。
- 核心可核点：现金流回收预测的依据与折现率、担保物价值数据来源、债务人/保证人偿债能力数据来源——涉及金额结论的须交叉验证。

## 七、⭐交叉验证适用规则（按本所明确要求）
- **涉及估值（报告给出价值数额或区间）的咨询报告**：**必须做交叉验证**——价值结论须经公开数据、可比交易、第三方数据交叉印证（尤其不得高估）。按 `data-sites.md` 优先查证；搜不到就**如实说明、绝不编造**；多来源、按用途/区位/业态/口径匹配。交付"交叉验证分析报告"（数据对比表＋可视化＋可点击来源链接）。
- **不涉及估值（纯定性分析、无价值数额结论）的咨询报告**：**不做交叉验证分析**。交付物只出 批注版 + 审核意见 两件。

## 八、常见问题清单（下结论前必查）
- 以咨询/估值报告规避依法必须的资产评估（重大合规）。
- 预设价值、迎合委托方结论；独立性存疑。
- 涉及估值却方法单一且无披露原因；参数无据、不可追溯。
- 信息资料未核验、或核验受限却未披露影响。
- 区间值未给最大可能值/未说明依据；使用有效期、使用限制缺失。
- 结论被超目的、跨场景使用（咨询结论当作评估结论用）。
- 与同时出具的资产评估报告口径矛盾（风险隔离不足）。
- 机构与人员资质、委托合同、附件缺失。（注：签字盖章属审核后出具时才办，不作为问题提出——见 SKILL.md 一节。）
- 模板残留、前后数据/主体矛盾。

**实务高频缺陷（北京评协462份样本统计，审核时重点扫这些）**：缺"估值程序实施过程和情况"(约53%)、缺附件(约33%)、缺估值人员签字(约50%)/缺机构章(约18%)、只用一种方法且未说明其他不适用原因(占一种方法报告约24%)、混淆同一途径的两种方法当作"两种方法"、两法相互引用结果未独立估算、估值目的未说明经济行为决策/批准情况(仅约13%披露)、市场价值以外价值类型未说明选取理由(约31%未说明)、两种以上方法未说明结论确定理由(约20%)、直接采用企业预测数据无调整/亏损转盈利无支撑/未调整溢余及非经营性资产负债。

## 交付物
- **涉及估值**：三件套（批注版报告[Word 真批注、直接描述问题、挂参照依据] + 审核意见[逐条自动连续编号、按文档大类分组] + 交叉验证[数据对比+可视化+可点击来源]）。
- **不涉及估值**：两件套（批注版报告 + 审核意见，**不做交叉验证**）。
格式见 `deliverable-format.md`。首步先问「审核人姓名」「批注人姓名」。涉及国有资产/司法处置的，分别叠加相应规则与 `judicial-disposal.md`。
