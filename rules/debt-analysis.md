# 债权分析报告（金融不良资产·债权价值分析）审核要点

> 依据学习：①**全文通读**《金融不良资产评估指导意见》(中评协2017,现行)；②**精读**程凤朝《金融不良资产评估》(人大社·方法论与审核底稿)、《中国不良资产管理评估实务》(现代实务·债权评估流程/偿债来源分析/核价)；③公开网络补充(金融监管总局2024《金融资产管理公司不良资产业务管理办法》等)。准则为核心，随审核迭代。

## 一、报告类型与定位（先分清是哪类业务/报告）
金融不良资产 = 银行次级/可疑/损失类贷款 + AMC收购或接管的不良债权 + 其他非银金融机构持有的不良债权（指导意见第2条）。
**两类业务，对应两类报告，审核口径不同（指导意见第7-9条）**：
| | 价值评估业务 | **价值分析业务** ⭐债权分析报告 |
|---|---|---|
| 前提 | 未受限、能履行必要评估程序 | 受限、**无法履行必要评估程序**（债务人不配合/无财务资料） |
| 成果 | 资产评估报告 | **价值分析报告等咨询报告** |
| 结论 | 基准日价值 | 基准日**价值或价值可实现程度** |
| 性质 | 评定估算专业意见 | 受限条件下专业意见，参考适用性**弱于**价值评估结论 |
- **审核首先判定项目应归为哪类**：能取得债务人配合+近期财务资料→宜价值评估(或偿债能力评估)；不能→价值分析。错配是首要问题。
- 报告须**明确说明两类区别**、提醒报告使用人；结论是处置参考依据，**非可实现价格保证**；明确有效使用期限（基准日后资产/市场重大变化须更新或重新评估）。

## 二、评估对象（指导意见第13-15条）
债权资产 / 抵债实物类资产(以物抵贷·抵债) / 抵债股权类资产(债转股·抵债股权·质押股权) / 其他资产(土地使用权·商标权·收益凭证)。须与委托人充分协商明确，关注具体形态对业务的影响。

## 三、价值类型
多为**非市场价值**（不良资产资料不全、处置时间紧、要求现金回收）：以**清算价值/强制变现价值**为主；债转股/重组/房地产可用持续经营价值；资本金用投资价值。报告须披露价值类型及定义、说明选择理由（与评估目的、处置方式匹配）。

## 四、分析方法（审核须核"方法↔前提条件"匹配）
**债权资产价值 = 信用债权价值 + 抵(质)押债权价值 + 保证债权价值**（三者之和，>债权金额则按债权金额封顶）。两大分析途径：

### A. 以债务人/责任关联方为对象（有配合/有资料时）
- **假设清算法**（停产/半停产企业）：三种清算价格(强制/有序/续用)。程序：债权资料分析→审计评估全部资产→剔除无效资产/无效负债→扣优先偿还债务(抵押债权/职工工资福利保险公积金/税金/涉诉)→扣优先费用(清算费/职工安置费**仅国企**)→一般债务总额→一般债权受偿比例→特定债权受偿金额→或有收益/新增偿债能力→受偿金额比例→特别事项。资产评估原则：应收款(函证+坏账比例法/账龄分析法)、存货(盘点≥80%)、设备(二手价/重置折扣不低于残值)、土地(划拨须列补缴出让金)、商誉零值、抵押资产(放弃优先权计入清算财产)。
- **信用评价法/现金流偿债法**（持续经营+财务规范+经审计报表）：信用评价法=32项指标(基本8+修正16+评议8、计量80%+非计量20%)→信用等级系数→贷款本息损失率→可变现价值=本金×(1-损失率)。现金流偿债法=以未来经营净现金流偿债能力折现。
- 信用债权回收率公式(实务)：停产企业、生产经营企业各有公式(总资产剔无效→优先扣除→÷调整后负债)；开工率<30%参照停产。
- **抵(质)押债权价值** = 抵质押资产可变现净值 − 优先于我方受偿债权 + 未受偿债权×信用债权回收率（可变现净值须考虑法院拍卖/变卖对价格影响及诉讼执行费用）。
- **保证债权价值** = 分析债务人+保证人偿债能力：一般保证=整体保证债权×债务人信用回收率+未清偿×保证人信用回收率；连带责任按债务人/保证人偿债能力孰高处理。

### B. 以债权本身为对象（债务人不配合/无资料时，债权分析报告核心）
- **综合因素分析法**(定性)：调阅剥离收购+信贷档案+调查→填"债权资料分析表"→给可变现价值比例区间或定性结论。资料历史性强、时效局限→宜定性。
- **交易案例比较法**(定量)：选**≥3个**可比交易案例(地域/债权形态/债务人性质行业/交易条件)→因素调整参数表打分(贷款时间/本息结构/剥离形态/行业/性质/规模/经营状况/信用/地域/市场/批量/时间/动机+抵押担保特殊因素)→案例回收比例÷分值得参照比例→按相似度加权(70%/30% 或 40%/40%/20% 或算术平均)。
- **德尔菲法/专家打分法**：专家10人左右(信贷/债务管理/不良处置/会计师/评估师/律师)匿名多轮反馈趋于一致(影响因素/权重/分值/折扣变现值)。
- **模拟拍卖法**：模拟拍卖竞价确定可变现价值。
- **偿债来源分析法**(收益法途径,现代常用)：以诉讼执行债务主体有效资产为前提，**穷尽全部受偿来源**(抵质押物变现/保证人偿债能力/股东出资不实抽逃补足/共同保证代位清偿追偿权益/信用债权)，逐一判断可受偿性与金额，汇总现值=债权价值。
- 定价模型 P=Σaᵢ·Kᵢ(原银行清分回收比例/项目组建议/中介咨询/处置委员/其他 各自权重)。

### C. 资产包(批量)定价
- **逐户定价加总法**：抵押物多样、同质化低、单笔金额大(对公/小微)。
- **抽样定价法**：笔数众多、同质性高、单笔占比小(信用卡/个人消费贷)；分层抽样(分行/借款人年龄/逾期天数/诉讼状态/抵押物类型与登记状态)；**超诉讼时效/有效法律文件缺失→定价为零**，剔零后按同类样本回现比率推算。

## 五、前提条件与资料（审核须核齐备性）
- 价值分析前提：债权债务关系证明(借据/合同/债权转移通知书/剥离清分资料) + 债权调查报告(债权形态·抵押担保·债务企业性质行业经营·图片·询价记录) + 一定数量类似债权处置成交案例。
- 关注：诉讼时效是否过期、抵押是否办他项权利登记(未登记不确认优先受偿权,但特别事项提示)、债权本身瑕疵、债务人/担保人主体存续(工商登记状态)。
- 独立性：机构及人员与委托人/被评估单位/相关当事人**无利害关系**(指导意见第5条)。
- 责任划分：资料真实合法性→委托人；报告本身合法性→机构；报告瑕疵→审核人。

## 六、债权分析报告审核重点（核心·我方质控）
### ⭐ 最高优先级：法律尽调报告 ↔ 债权分析报告 的匹配程度（送审材料含法律尽调报告时）
**当送审材料包含法律尽职调查报告（法律意见书）时，二者的匹配/吻合程度是债权分析报告审核的最高优先级标准，须先核此项再核其余。** 法律尽调确立债权的法律事实，债权分析报告的对象、假设、受偿来源、结论必须与之一致，逐项核对：
- **债权真实性、有效性、合法性**：分析报告认定的债权金额（本金/表内外利息/孳生息）、债权债务关系，是否与尽调结论一致。
- **诉讼时效**：尽调认定是否超过诉讼时效/是否中断中止；分析报告对超时效债权是否**定价为零或重大折让**——不得对尽调认定已丧失胜诉权的债权给出正常变现比率。
- **抵(质)押/担保的设立与效力**：尽调认定抵押是否办理他项权利登记、是否有效、顺位、是否存在在先查封；分析报告**确认优先受偿权的前提必须以尽调认定的有效担保为准**——尽调认定抵押未登记/无效/顺位靠后的，分析报告不得据此享有优先受偿。
- **债务人/保证人主体状态**：尽调认定的工商存续/注销/吊销/破产、保证责任(一般/连带)、保证期间是否经过；分析报告的受偿来源与可偿能力分析须与之衔接。
- **权属与瑕疵**：尽调披露的权属瑕疵、未决诉讼、代位/共同保证追偿权益等，分析报告是否对应反映并恰当处理。
- **不一致即重大问题**：凡分析报告结论（尤其优先受偿、变现比率、受偿来源）与法律尽调认定相冲突、或超出尽调支持的范围，应作为最高级别审核意见提出，要求修正或在特别事项充分披露并说明依据。
- 若**未附法律尽调报告**：核分析报告是否就上述法律事项取得其他有效证据（权属证明、登记查询、承诺函），证据不足的须在特别事项披露并提示风险。

**三大分析途径**（程凤朝Ch6 / 实务"核价"）：
1. **程序/过程审核**：机构与人员资质(评估咨询资格、公章/承诺函)；报告内容格式完整规范；尽调程序是否合规(非现场+现场+外围、逐户或抽样)；取价依据/产权依据是否充分；附件齐全。
2. **方法审核**：方法与前提条件是否匹配(综合因素法-是否取历史资料并分析；交易案例比较法-是否**≥3可比案例并因素修正**；德尔菲法-专家是否恰当)；处置策略/回收来源/回收金额/处置成本/处置时间测算是否合理客观；回收可实现性与风险是否充分考虑。
3. **逻辑审核**：分析过程步骤是否合逻辑；尽调信息↔分析结果的**勾稽关系**；与法规政策、地区经济、市场价格、企业历史是否吻合；是否充分考虑快速变现、合理折扣变现率。
**债权确值合理性**：建议变现比率/可变现价值的依据是否充分、是否过度依赖意向投资者报价或保底清收金额(2024办法禁止简单定价)。
**审核工作底稿（表6-15·9项规范性审核，逐项是/否+初审/复审）**：①机构出具报告条件 ②报告公章 ③承诺函 ④内容格式完整正确 ⑤分析过程步骤合规 ⑥取价依据产权依据充分 ⑦参数依据充分 ⑧附件完整正确 ⑨分析结论合理。

## 九、民法典审核要点（精读·债权/担保物权，替代旧合同法担保法）
**债权转让(合同编)**：①第545条债权可全部/部分转让(性质·约定·法律不得转让除外；约定金钱债权不得转让不得对抗第三人)；②**第546条债权转让须通知债务人，未通知对债务人不发生效力**(债权分析报告须核转让通知)；③**第547条受让人取得从权利(担保/抵押一并转让)，不因从权利未办转移登记或未转移占有受影响**；④第548条债务人对让与人的抗辩可向受让人主张、第549条抵销。
**担保物权(物权编)——抵押/优先受偿审核红线**：①**第402条不动产抵押自登记时设立**(未登记不享优先受偿——与法律尽调核对的关键)；动产抵押合同生效设立、未登记不得对抗善意第三人(403)；②**第405条抵押前已出租并转移占有的，原租赁关系不受抵押权影响(买卖不破租赁)**；③第406条抵押期间抵押人可转让抵押财产、抵押权不受影响(转让须通知抵押权人)；④**第414条同一财产多抵押清偿顺序：已登记按登记时间先后→已登记先于未登记→未登记按债权比例**；415条抵押+质押按登记/交付先后；⑤第417条建设用地使用权抵押后新增建筑物不属抵押财产(实现时一并处分但新增建筑物价款不优先受偿)；⑥**第419条抵押权须在主债权诉讼时效期间行使，逾期法院不予保护**；⑦**权利质权(440-445)**：应收账款/股权/基金份额/可转让知识产权财产权出质须**登记**设立(债权资产含质押权益时核登记)。
**诉讼时效**：第188条普通诉讼时效**3年**(债权分析报告须核债权是否超时效——超时效丧失胜诉权应定价为零或重大折让，与法律尽调一致)。
> 来源：精读《民法典》物权编担保物权分编(395-457)、合同编债权转让(545-550)、总则诉讼时效(188)。担保法/合同法相关内容已由民法典取代。
