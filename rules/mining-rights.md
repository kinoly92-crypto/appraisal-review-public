# 矿业权评估报告审核要点（探矿权 / 采矿权）

> 依据全读：①**《中国矿业权评估准则》(2011，全部)** = 评估师职业道德基本准则 + 技术基本准则(CMVS 00001-2008) + 技术规范(程序11000/约定书11100/底稿11200/档案11300/**报告编制11400**/收益途径方法12100/成本途径方法12200/市场途径方法12300) + 应用指南(价款20100/转让20200) + 指导意见(基准日30200/利用资源储量30300/利用地勘文件30400/后续地勘30500/矿山设计30700/**参数确定30800**/利用企业财务报告30900) ；②**《矿业权出让收益征收办法》(财综〔2023〕10号，2023-5-1施行，全读)**；③**《矿业权出让收益评估应用指南(2023)》(中国矿业权评估师协会2023年第1号公告，2023-5-1施行，替代2017试行版，全读)** —— 出让收益评估业务的执业操作规范。叠加：《资产评估法》《矿产资源法》、若为司法处置项目叠加 `judicial-disposal.md`。**矿业权评估程序以本套 CMVS 11000 程序规范为主，但矿业权亦属资产评估准则体系——评估基准日 ≥ 2027-01-01 的项目，《资产评估执业准则——资产评估程序》新版（2027-01-01 施行，废止中评协〔2018〕36号）的强制要求可参照并入，重点：内部（分级）审核与业务报备为独立强制程序、程序受限"无法判断影响程度不得出报告"、正式报告须先报备再出具且与报备系统一致、评估假设独立披露——详见 `asset-appraisal.md §一B`。**

## 一、报告识别与基本定位
- **矿业权 = 探矿权 + 采矿权**，属用益物权（民法典329条），评估对象是矿业权价值（矿产资源所有权归国家，评估的是归属矿业权人的那部分收益现值）。
- **先判经济行为/评估目的**（价值内涵不同，审核口径随之不同）：出让价款 / 转让 / 抵押贷款 / 法律诉讼(司法处置) / 上市融资信息披露 / 非正常矿山关闭补偿 / 企业改制作价出资。报告封面/标题/评估目的应与之一致，且**评估结论不得跨目的使用**（须在使用限制中披露）。
- **签章规则**（11400报告编制规范）：报告须由**两名注册矿业权评估师签字**+评估机构法定代表人签字+机构盖章；机构与人员资质有效（涉司法的须在法院名单库内）。**※这是"应当如何签章"的资格/一致性要求（须核署名人资质、与执业登记一致、机构资质有效）；但签字盖章在审核通过、报告出具时才完成，本次审核"缺签字/缺法定代表人签字/缺机构章"不作为问题提出（见 SKILL.md 一节）。**
- **报告16项基本内容**应齐全：标题与文号、绪言、声明、摘要、正文(委托方/产权持有人/目的/对象与范围/价值类型/基准日/依据/方法/过程/假设/结论/特别事项/使用限制/报告日)、附表附件。**评估结论应同时以文字和数字表达**。**※审核在出报告前进行，报告文号此时尚未生成——其余15项照核，"缺文号/无文号"不作为问题提出（见 SKILL.md 一节）。**

## 二、资源储量与年限（最易出错、最高频审核点）
1. **资源储量分类参与规则（30300）**：以经**评审备案**的资源储量报告为准。
   - 探明(331)/控制(332) 经济基础储量：**可信度系数=1.0**，全额参与。
   - 推断(333)：**可信度系数 0.5～0.8**（据地质可靠程度取值并说明依据），打折参与。
   - 预测(334?)：**不参与**评估计算。
   - 核查：报告利用的资源储量是否=备案储量×可信度系数，是否混入未备案/不可参与储量；动用储量、可采储量(=利用储量×回采率)推导是否正确。
2. **是否已有偿处置**：评估利用的资源储量若部分/全部未有偿处置（未缴出让收益/价款），须在报告披露并提醒当事方在交易定价时考虑（呼应2023办法第15条动用未处置储量需补缴）。
3. **评估计算年限**：
   - 受**可采储量、设计生产能力、采矿许可证剩余年限**共同约束；
   - **2023办法第14条 / 2011准则：评估期限要与采矿权登记发证年限、矿山开发利用实际有效衔接，且最长不超过 30 年**；
   - 服务年限 = 可采储量 ÷ (设计生产能力×贫化/回采调整)，再与证载年限取短；超证载年限或超30年的须核减。

## 三、评估途径与方法适用性（三途径9法）
- **收益途径(12100)** 5法：折现现金流量法(DCF) / 折现剩余现金流量法(DRCF) / 剩余利润法 / **收入权益法** / 折现现金流量风险系数调整法。适用于资源储量可靠、能可靠预测未来收益的采矿权及可转采的探矿权。
- **成本途径(12200)** 2法：勘查成本效用法 / 地质要素评序法。适用于早期探矿权（投入成本与价值存依存关系、未来收益难可靠预测）。
- **市场途径(12300)** 3法：可比销售法 / 单位面积探矿权价值评判法 / 资源品级探矿权价值估算法。须有足量可比交易案例；**相似参照物不得选取招拍挂等特殊交易方式形成的、或以处置价款为目的的案例**。
- 审核：方法选用与勘查/开发阶段（预查—普查—详查—勘探—拟建—在建—生产—闭坑）是否匹配；多方法时取值与差异说明是否合理；探矿权用收益法须以"依法可转采矿权"为前提并披露。

## 四、关键评估参数审核（参数确定指导意见 CMVS 30800-2008）
> 五原则：时效性(基准日时点价费水平)、有效性(所据法规未废止)、谨慎性、合理性、灵活性(不同经济行为/阶段/地区价值不同，不得简单套用参考资料)。
1. **折现率(4.17)**：折现率 = 无风险报酬率 + 风险报酬率；**不得低于安全利率**；与收益口径一致。无风险报酬率取长期国债票面利率或人行五年期定存利率（**不宜用上市国债市场收益率**，有市场风险）。风险报酬率建议用**"风险累加法"= 勘查开发阶段风险 + 行业风险 + 财务经营风险**（参考表4-8）。核查折现率与投资、价格、成本等参数是否作整体合理性判断。
2. **采矿权权益系数(4.13)**（收入权益法等用）：基准表对应折现率8%；按矿体埋深、地质构造复杂程度、矿石选冶性能、开采方式、水文工程地质条件取值——**条件好取高值、差取低值**；折现率≠8%时须按调整系数公式换算。核查取值依据与矿山实际是否相符。
3. **矿产开发地质风险系数(4.14)**（探矿权用）：反映资源储量的地质可靠程度风险。
4. **生产能力(4.1)/产品方案/采选技术指标**：应与可研、矿山设计、开发利用方案一致；以企业实际为基础时须关注资源禀赋差异。
5. **产品价格(4.11)**：与产品方案口径一致；分析历史价格趋势合理预测；价款评估通常前3年（大中型矿5年）按近期价格、之后按长期均价（详见价款应用指南）。
6. **投资与流动资金**：固定资产投资据设计/可研；流动资金按分项详细法或扩大指标法；土地使用权摊销年限取剩余年限与评估年限孰短。
7. **税费(第二章)**：增值税(金属/非金属/煤等采选产品销项**13%**)、企业所得税**25%**(西部大开发等区域优惠按目的判断是否考虑；价款评估通常不考虑优惠减免)、矿产资源补偿费(销售收入×**费率0.5%~4%**×回采率系数，建议计入管理费用)、资源税(从量/从价按最新政策)、安全费用(就高选取)、维简费、城建税(市7%/县镇5%/其他1%)、教育费附加3%+地方附加。须按基准日有效政策、最新实施标准计取。

## 五、《矿业权出让收益征收办法》(财综〔2023〕10号) 审核要点
- **出让收益 = 探矿权出让收益 + 采矿权出让收益**；中央与地方按 **4:6** 分成。两种征收方式：
  - **按出让收益率逐年征收**：适用《矿种目录(试行)》25类矿种（如石油陆域0.8%、煤炭2.4%、铁锰铬钒钛1.8%、铜铝镍钴1.2%、钨锡锑钼铅锌2.3%、金银铂族2.3%、轻稀土2.3%、中重稀土4%、磷2.1%、宝玉石8%、矿泉水3%等）。逐年采矿权出让收益 = 年度矿产品销售收入(不含增值税) × 出让收益率。
  - **按出让金额征收**：目录外矿种；协议出让按**评估值与市场基准价测算值就高确定**。
- **评估期限 ≤ 30 年**且与采矿证年限、开发实际衔接（第14条）；动用评估范围外储量须另行处置。
- **市场基准价**原则上每三年更新一次；起始价由省级据指导意见制定。
- **分期**：首次征收比例 10%~20%（自愿一次缴清除外），中型及以上矿均摊年限不少于采矿证有效期一半。
- **滞纳金**：未按时足额缴纳的，自滞纳之日起按日加收 **2‰**，不超过欠缴本金。
- 审核用途提示：出让/转让收益评估若引用本办法收益率、基准价，须核对矿种归类、计征对象(原矿/选矿产品)、收益率取值与目录一致；与价款/出让收益相关报告须区分"成交价"与"逐年收益"。

## 五B、出让收益评估专项（《矿业权出让收益评估应用指南(2023)》——出让收益评估项目逐条核）
> 出让收益评估是矿业权最高频业务（自然资源主管部门确定出让收益金额用），审核须额外套用本指南。
1. **委托与定位**：委托人**由自然资源主管部门确定**；报告须披露**评估结论仅供自然资源主管部门确定出让收益金额参考、与实际确定金额不必然相等**(1.4)。自然资源主管部门有特殊规定的从其规定。
2. **承办与签章(1.3)**：至少**两名"矿业权价值评估专业"矿业权评估师**承办（核承办资格）；签字盖章+机构印章在审核后出具时完成，"缺签字盖章"不作为问题提出（见 SKILL.md 一节）。
3. **报告统一编码(6.5)**：出具时须取得**中国矿业权评估师协会评估报告统一编码**——核查报告是否载明编码。
4. **方法选择(7，比一般评估更窄更细)**：出让收益评估**仅可用** 收益途径(折现现金流量法DCF / 收入权益法) + 成本途径(地质要素评序法 / 勘查成本效用法) + 市场途径(可比销售法 / 单位面积探矿权价值评判法 / 资源品级探矿权价值估算法)——**不含DRCF、剩余利润法、风险系数调整法**。选法按勘查程度：
   - **普查探矿权**：未估算资源量→勘查成本效用法（空白地/少量地质工作→单位面积探矿权价值评判法）；已估算资源量→地质要素评序法（资源量较多→资源品级探矿权价值估算法）；煤/磷/铁/铝土矿等赋存稳定沉积型矿床且服务年限≥10年→DCF（不具备DCF条件→收入权益法）。
   - **详查、勘探探矿权及采矿权**：服务年限≥10年→DCF；不具备DCF条件→收入权益法。
   - 可比因素可确定、指标可量化时→**同时**选可比销售法。
5. **服务年限(8.3.1)**：原则上**由委托人按出让收益征收管理规定确定**（呼应2023办法≤30年、与采矿证衔接）。
6. **资源量(8.3.2)**：以地勘文件/储量报告为基础（需评审备案的须含评审意见、备案文件）；按 **GB/T 17766-1999** 编制的委托人须按自然资源部要求做**数据转换**，按 **17766-2020** 编制的须关注资源量与储量关系并披露；工业指标取一般工业指标或论证批复指标；共伴生组分技术经济环境可行的应纳入评估范围。
7. **⭐折现率(8.3.6，出让收益评估硬标准)**：据原国土资源部公告2006年第18号——**勘探以上的探矿权及(申请)采矿权出让收益评估，折现率取 8%；详查及以下的探矿权出让收益评估，折现率取 9%**。（出让收益评估直接按此取，区别于一般评估的风险累加法。）
8. **产品销售价格(8.3.4)**：取代表当地市场水平的资料；**一般取基准日前3个年度价格平均值**；价格波动大、服务年限长的大中型矿可取**前5个年度**均值；服务年限短的小型矿取**当年价格平均值**；依据与过程须披露。
9. **税费(8.3.5)**：增值税按一般纳税人适用税率；企业所得税以**利润总额为基数**按税率计、**不考虑亏损弥补及所得税减免抵扣等优惠**。地质要素评序法/勘查成本效用法的工作量取价按基准日适用的地勘项目预算标准（暂缺的参考相关行业标准）。
10. **评估结论与有效期(11)**：结论须含出让收益评估值及对应资源储量；与市场基准价比较建议整体比较；**使用有效期1年**——评估结果**公开的自公开之日起、不公开的自评估基准日起**计1年。
11. **披露(12)**：报告须完整披露委托人/基准日/目的/对象范围/依据/过程/方法选择/参数选取/结论/假设/使用限制与特别事项；**须披露以往矿业权有偿处置情况**及其他对结论有重大影响事项；报告主题词含 勘查项目名/矿山名 + 探矿权/采矿权 + 出让收益评估报告。
12. **增列矿种/增加储量、退还评估(9、10)**：原则上独立评估；不能独立的按销售收入比例分割；政策调整退还按指南公式核算。
13. **按金额征收的建材类矿种(附录)**：石灰岩/白云岩/石英岩/砂岩/天然石英砂/页岩/耐火粘土/各类粘土/橄榄岩蛇纹岩玄武岩等基性-酸性岩/大理岩板岩片麻岩等——这些目录外矿种按出让金额（评估值与市场基准价就高）征收，核对计征方式勿误用收益率。

## 六、交叉核查（报告↔说明/测算表↔权属与储量备案↔法律资料）
- **权属**：采矿/探矿许可证（矿区范围拐点坐标、有效期、生产规模、开采矿种、开采方式）↔报告口径一致；探矿权评估须有划定矿区范围批复或可转采依据。
- **储量**：备案的资源储量报告/评审意见 ↔ 报告利用储量、可信度系数；图件(储量估算图)与文字一致。
- **生产经营**：近三年财务报表、开发利用方案/可研 ↔ 生产能力、成本、技术指标。
- **出让收益/价款缴纳材料** ↔ 是否存在未处置储量、是否需补缴。
- **抵押目的**：审慎原则，关注变现能力与风险提示，不得高估；与司法处置目的区分（司法处置叠加 `judicial-disposal.md`：市场价值、不考虑查封担保、不考虑处置费用）。
- 数值复算：销售收入、经营成本、税费、净现金流、折现、可采储量、服务年限逐项复核；公开数据(矿产品价格、同类矿业权交易)交叉印证估值合理性，搜不到如实说明、不编造。

## 七、常见问题清单（下结论前必查）
- 资源储量未经评审备案即参与，或333未打可信度系数、334参与计算。
- 评估计算年限超采矿证年限或超30年未核减。
- 折现率低于安全利率、或与收益口径不一致、或风险报酬率无依据。
- 权益系数取值与矿山地质开采条件不符、折现率非8%未做调整。
- 产品价格脱离市场趋势、税费未按基准日最新政策（增值税率/资源税/补偿费率）。
- 出让收益率矿种归类错、计征对象(原矿/选矿)错、收益率与目录不符。
- **出让收益评估专项**：折现率未按勘探以上8%/详查及以下9%取（误用风险累加法）；选用了DRCF/剩余利润/风险系数调整法（出让收益评估不可用）；方法与勘查程度不匹配（普查/详查勘探选法见§五B.4）；产品价格未按前3年(大中型/波动大前5年、小型当年)均值；所得税考虑了减免优惠或亏损弥补；缺协会报告统一编码；有效期口径错（公开自公开日/不公开自基准日起1年）；未披露以往有偿处置情况。
- 机构/人员资质或司法名单库缺失；承办署名人不符合"两名相应专业类别评估师"或与执业登记不一致。（**注：单纯"此刻缺签字/缺法定代表人签字/缺机构章"属审核后才办，不作为问题提出——见 SKILL.md 一节。**）
- 评估目的与使用限制不匹配、结论跨目的使用、未披露瑕疵事项与未处置储量。
- 模板残留/前后矛盾（矿区名、坐标、储量、单位、矿种张冠李戴）。
