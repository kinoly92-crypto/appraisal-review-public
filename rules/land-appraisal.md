# 土地估价报告 审核要点

## 报告类型特征
- 通常含「土地估价报告(结果)」+「土地估价技术报告(评估工作底稿)」；常为一个文档。批注版出**1 份**。
- 交付物三件套，格式同 `deliverable-format.md`。审核意见大类可为「土地估价报告/土地测算表」。

## 核心依据
- **核心=《城镇土地估价规程》GB/T18508-2014**（及其附录E 报告规范格式）。
- **出让目的（含补缴地价）必依《国有建设用地使用权出让地价评估技术规范》（国土资厅发〔2018〕4号·"4号文"）**；**4号文与GB/T18508冲突时以4号文为准**。配套《土地估价参数调查测算指引》（成本逼近法增值收益、未监测城市期日修正系数等）。
- 配套：GB/T18507 城镇土地分等定级、TD/T1052 标定地价规程、TD/T1009 城市地价动态监测(地价指数)、GB/T28406 农用地估价(涉农用地时)、GB/T28405 农用地定级、GB/T28407 农用地质量分等、TD/T1071 园地分等定级；TD/T1008 土地勘测定界(核面积/四至)。TD/T1018/1029 集约利用评价属土地利用效率评价、非估价(背景)。

## GB/T18508 审核要点
- 适用：城镇/独立工矿区建设用地"基准地价"与"宗地地价"评估；农村建设用地参照。
- 地价类型：公示地价(基准地价/标定地价/课税地价)、宗地地价。
- **估价原则**：替代/最有效利用/预期收益/供需/贡献。
- **五大估价方法**：①市场比较法 ②收益还原法 ③剩余法(现有不动产中土地价/待开发土地价两类) ④成本逼近法 ⑤公示地价系数修正法(含基准地价系数修正法/路线价法/标定地价系数修正法)；+级差收益测算确定法。
  - **关键红线：每项估价所选估价方法应≥2 种**(除标准规定特殊情况)；理论上推荐而未选用的方法须说明不选用理由。
  - **市场比较法**：P=PB×A×B×C×D×E；比较实例**≥3**，估价期日距交易日**原则上≤3年**(注：比《房地产估价规范》的2年宽)；同一供需圈、用途相同；**估价期日修正用地价指数**(依TD/T1009)；9种特殊交易不宜选；**容积率对地价影响大时应单独修正**；年期修正 K=[1-1/(1+r)^m]/[1-1/(1+r)^n]。
  - **收益还原法**：P=a/r(永续)或有限年期式；出租资料宜3年以上、营运5年以上；土地纯收益=总纯收益扣非土地因素。
  - **成本逼近法**：P=土地取得费+开发费+税费+利息+利润+土地增值；建成区已开发宗地设定开发程度最少"红线外通路通水通电+红线内平整"；已出让土地作剩余年期修正；适用新开发/少交易地区。
  - **公示地价系数修正法**：基准地价系数修正(基准地价距估价期日**≤3年**)/路线价法(区域同时存在基准地价与路线价时，里地线内用路线价)/标定地价系数修正(标定地价距期日**≤1年**, 可比标准宗地≥3)。
- 价格影响因素：一般/区域/个别。
- 宗地估价程序(8步)：明确估价基本事项→拟订作业方案→收集资料→实地查勘→选方法试算→确定结果→撰写报告+技术报告→归档。

## 报告规范格式（附录E，审核对照）
- 「土地估价报告」四部分=封面/第一部分摘要(项目名称·委托方·估价目的·估价期日·估价日期·**地价定义**·估价结果·估价师签字·估价机构)/第二部分估价对象界定(委托方·估价对象·概况[土地登记/权利/利用状况]·影响地价因素[一般/区域/个别])/第三部分估价结果及使用(估价依据·原则·方法·结果·前提假设·使用限制·特殊说明)/第四部分附件。
- **地价定义须注明**：公开/特定市场、估价期日、现状/规划利用、**设定的开发程度(几通+平整)与用途**、法定最高年限内一定年期、权利特征。
- 估价依据应与估价过程一致(方法选择/参数确定所依据文件列名称文号)。
- 估价结果：总地价+单位面积地价(必要时楼面地价)、大写；**涉及抵押应注明结果是否含法定优先受偿款及处置税费等**。
- 签章规则＝**至少2名注册土地估价师签字(注明注册证书号)+机构法定代表人签字+加盖机构公章**（核署名资格与一致性；签章本身审核后出具时才完成，"缺签字/缺公章"不作为问题提出——见 SKILL.md 一节）。报告有效期自提交日起原则上≤1年。
- 附件：委托函/营业执照/**权属证明(土地证复印件；估价师须验对原件后在复印件加盖估价机构公章)**/出让合同/规划材料/宗地位置图/估价对象及**比较案例照片**/现场查勘记录表/估价师证书。
- **技术报告**(评估工作底稿)：各方法须详述；比较因素条件说明表(E.2)/指数表(E.3，估价对象各因素=100基础)/修正系数表(E.4)；**因素描述须具体量化、不得用"相同/较好/接近/较差"等无含义用语**；**估价对象因素条件说明须与"影响地价因素分析"一致、避免前后矛盾**(高频抓手)；舍弃某方法结果/增减值调整须说明理由；涉多市县须分市县出具；字体A4、封面二号标宋三号楷体、正文三号标宋四号仿宋。

## 质量关注点与严重程度分级（《土地估价报告质量关注点·2025版》·实务抓手）
> 含问题分级：**严重问题 / 较严重技术问题 / 打分降档**。备案与机构函部分以山东省为例（备案函由省级自然资源厅印发），技术要点与分级普遍适用；外省按属地备案系统与省级评审标准对应。

**一、电子化备案**：报告提交委托方前须在**全国土地估价监管系统**(tdgj.mnr.gov.cn)"报告备案"取电子备案号，应备尽备。

**二、形式要件**
- **机构备案函**：上传与作业日期对应的**最新备案函**（2020-11前无二维码的可与最新附记页合并上传）；未附或不符=**较严重问题**。
- **附件清单**（依GB/T18508+4号文，不少于）：签字盖章页、结果一览表盖章页、现场勘察表、委托资料(委托函/书/合同)、宗地位置图、**产权证明(抵押须含产权证附记页)**、规划资料(出让目的；未提供须委托函明确重要规划指标)、**现场照片(能证明≥1名签字土地估价师持现场查勘证书勘查的正面照、反映整体利用)**、市场比较法可比案例位置图/现场照片/成交信息、特殊技术处理依据文件。须清晰完整规范。
- **《基本信息表》**：勾选方法与报告实际方法**一致**（剩余法一[已建成]/剩余法二[待开发]易错配）；混合用地/多宗地分地块申报，勿漏报。
- **签字盖章规则**：机构公章+**≥2名承办土地估价专业人员签名**+法定代表人签字/盖章；**结果页须体现签章**(不在同页须补盖章结果页/一览表)；签字人须与备案函一致；**不得以个人名章/签字章代签字、不得以估价专用章代机构公章**。**※以上是"应当如何签章"的资格/一致性规则，须核署名人是否符合且与备案函一致；但签字盖章在审核通过、报告出具时才完成，本次审核"缺签字/缺机构章/未盖章"不作为问题提出（见 SKILL.md 一节）。**
- **完整性**：上传须含**土地估价报告 + 技术报告(工作底稿)**。

**三、报告内容**（出让地价严守GB/T18508+4号文）
- **地价定义**：设定依据充分清晰完整（市场状况·期日·用途·价格类型·年期·面积·利用条件·开发程度·提供参考目的）；**地价内涵一致性**(地价定义↔估价结果↔方法应用)——抵押目的"市场价格/抵押价值"界定不清、**未正确处理优先受偿款**=**较严重技术问题**；补缴地价：**估价期日=主管部门依法受理补缴申请时点**、定义为正常市场价格。
- **地价影响因素**：一般因素按宗地所在行政区划地位/城市规模(不空泛，如位于章丘区龙山镇应重点描述章丘+龙山镇而非只描济南)；区域因素突出**中观区位**与结合度；个别因素**须与现场照片一致**；时效性(勿用陈旧资料)、针对性、**与方法参数对应**(方法中需修正的因素须在因素分析中说明、逻辑一致；工业用地勿只描述住宅地价)。
- 估价依据(关注文件**有效性**)、估价原则(按对象与目的选择、体现应用)。
- **出让报告**：估价目的/地价定义/结果/依据/原则/方法选择与应用/附件等**5处以上不符4号文=降档**。

**四、方法运用红线**
- **至少两种方法，否则严重问题**；出让目的按4号文"**收益还原法/市场比较法/剩余法 三选一**"+"**成本逼近法/公示地价系数修正法 二选一**"；**避免方法选而不用**(无法满足须详细市场调查说明)。
- **收益还原法**：客观收益费用(出让年期内稳定)；测算收益的比较实例**≥3且报告含市场比较法测算过程**；还原率说明方法依据；明确重置/重建成本。
- **市场比较法**：描述案例选择过程；优先正常交易，**不用竞价轮次多/溢价率高/楼面地价历史最高最低**的实例；**不得用评估案例**；用途不一致案例须析替代性(否则较严重技术问题)；因素修正系数表完整针对、取值理由、与因素分析一致；权重比例理由；**4号文：各比准价格相差≤40%、各修正幅度≤30%**。
- **剩余法**：一(已建成,不动产交易价客观论证)/二(待开发,先定最佳开发利用方式：用途·容积率·密度·布局·层数·结构·高度·开发周期·地上地下·配建代建·混合用地占比；售价取正常水平；**开发周期一般≤3年，超须充分理由**)；公式数值测算详准、增值税清晰。
- **成本逼近法**：关注取得方式与成本构成；征收方式**按区片综合地价**；**国家/地方从出让收入收益计提的专项资金、新增建设用地有偿使用费不得计入成本；土地管理费已取消不再计入**；耕地开垦费规范(避免直接引用占补平衡指标替代)；成本参照客观费用、与基准地价及开发程度对应；增值收益符合《参数测算指引》。
- **基准地价系数修正法**：重点**适用性分析**——基准日期**已过3年须做适用性分析/合理确定期日修正系数(否则降档)**；**不得使用已过6年的基准地价**；地价内涵界定+政府公布文件号及实施时间；修正体系完整(条件说明表/条件指数表/容积率修正/开发程度修正)；因素描述具体(如"南邻经十路"而非"一面临路")；用途/权利差异调整按GB/T18508、自增修正项不合理=严重问题(合理但不规范=较严重)。

**五、其他**
- 可信度分析、**出让项目须有出让底价建议**(过简不行)；使用说明须有针对性；**附件与报告不一致(面积/剩余年限等重要参数)=降档**；**计算错误/结果前后不一致=严重问题**；书写笔误(公式/年期/用途/面积/容积率前后不一致)=较严重技术问题；**未明确表述为咨询性的抵押评估报告，按抵押评估报告评审标准审查**；地下空间须在地价定义/结果/个别因素/特殊说明清晰界定并附依据文件；**多宗地每宗均须测算过程，不得用"同上可得/参照可得/同理可得"直接得结果**。

## 云南省土地估价报告评审标准（2022-07施行·百分制评分细则·云南项目核心审核标尺）
> 全文细读。百分制、五等级、含一票否决与降等规则。是云南项目土地估价报告审核的权威标尺；外省作方法论参照。

**⭐一票否决（直接判五等不合格，但仍须逐项打分指出问题）**：①签字师不在《备案函》名录/用合同章财务章代机构公章（**注：这一项指署名资格与签章规则的违规；至于"此刻尚无签字、尚未盖公章"属审核后才办，不作为问题提出——见 SKILL.md 一节**）；②**使用超过6年的基准地价**；③**未经省级以上协会专家论证仅用一种方法评估**；④机构未在省自然资源厅备案。

**评分结构(100分)与权重**：封面1 + 第一部分总述18(目的2/依据2/期日与日期1/**地价定义4**/结果2/报告与结果使用5/签字盖章2) + 第二部分对象描述及地价因素15(对象7=界定1+登记2+权利3+利用1；因素8=一般2+区域2+**个别4**) + **第三部分土地估价57(原则2/方法2/过程50/地价确定3)** + 第四部分附件4 + 总体评价5。
- **过程50分按方法数均分**：两法各25 / 三法各16.67 / 四法各12.5。多宗地同一方法用≥2次，专家可只评一次。

**三档问题严重度**：①**估价报告整体修正降等**（地价定义设定/与委托函或过程/结果不一致、出让方法不符4号文、补缴地价直接按地方规定与4号文冲突、目的≥2个或对象不符处置规定、封面不按系统生成/编号不连续、套模板未替换降0.5等）；②**一般严重问题（该子项计0分）**（结果页无章扣2分外、用评估案例充当成交、抵押附件缺产权证明/附记页/遮挡、成本逼近法未执行4号文专项资金等规定、剩余法一二混用、计算错误/结果前后不一致/混合用地不符39号文）；③累计≥5项"子项计0分"→整体降等扣10分；书写笔误累计≥3处降0.5等、≥5处降等、致结果显著偏差不限项数。

**各方法过程审查要点（评分点）**：
- **市场比较法**：实例≥3+照片+真实可比(用途一致/同供需圈/期日≤3年；近三年相似区域不足3例原则上不用市场比较法)；可比因素含全部主因素(交易时间/情况/方式或价格类型/年限必选+区域+个别)，与第二部分因素前后对应；条件说明客观量化一致；**4号文：单实例修正幅度≤30%、各比准价格相差≤40%(超须替换)，中估协单因素修正≤20%**；权重理由。
- **收益还原法**：总收益(案例可比/收益内涵/出租3年以上·营运5年以上资料/客观收益由市场比较求证+衍生收益)；总费用参数全面有据；房屋纯收益(重置价/折旧/现值/还原率)；土地纯收益；土地还原率(纯收益价格比率法/安全利率加风险调整/排序插入法)；出让评估收益假设出让年期内稳定、测算收益比较实例≥3。
- **剩余法一(已建成含地价)**：不动产总价(市场比较/收益法)→房屋重置价→折旧(物理/功能/经济)→现值→交易税费(土地分摊部分)→地价。**剩余法二(待开发=假设开发法)**：先定最佳开发利用方式(用途/容积率/密度/层数/结构/高度/开发周期/地上地下/配建)、售价取出让时正常水平(不用估算未来售价)、**开发周期一般≤3年**、利息复利(销售税费不计息)、利润率匹配计算基数(现金流折现则利息利润不单列)、可售面积≠总建面。**一二混用且无充分理由=技术路线错误**。
- **剩余(增值收益扣减)法**(划拨地·自然资办函2019·922号)：出让价扣土地增值收益；未公布增值收益地区须满足数理统计自行测算，**不得直接按出让金缴纳比例扣减**。
- **成本逼近法**：土地取得费(征收按法管法及当地规定，市场差距大须≥3征地实例比较；个例性支出不入成本)→开发费(区域同类客观水平、区分宗地内外"几通一平")→税费→利息→利润→土地增值收益→年期/区位修正。**4号文：专项资金(农开/收益基金/农田水利/教育/安居)、新增建设用地有偿使用费、指标流转费不得计入成本与底价**；耕地占用税/开垦费规范。
- **公示地价系数修正法**：基准地价简介(内涵/公布时间文件/期日/开发程度/容积率/年期)+修正体系；基准地价距期日≤3年(3-6年须解释必要性+可用性+定量趋势分析+期日修正；>6年禁用，用经验收未公布的计子项0分)；待估宗地因素条件说明表与修正体系表一致、取值与说明吻合；开发程度/容积率/期日修正。

**地价确定(3分)**：可信度分析、最终取值依据与方法(算术/加权/众数须说明权重理由)。**附件(4分)**：抵押须上传产权证明含附记页且清晰不遮挡(缺=子项0分)；机构备案函必备(已备未按要求上传降0.5等扣5分，未备案直接不合格)。**五等级**：一等90-100/二等80-89/三等70-79/四等60-69/五等<60。连续两次≥二等免检一年。

## 实战常见问题（来自真实审核）
容积率设定前后矛盾(结果报告 vs 技术报告)；价值时点与取得时间/报告日关系；市场比较法**交易期日未修正**(指数全取100)；可比案例可比性弱(级别/容积率/面积差异大)；两种方法结果差异大未充分分析；表头/术语模板残留("收购"vs"抵押"、"注册房地产估价师"应为"土地估价师")；容积率按规划满容设定 vs 现状强度；租赁权等他项权利的矛盾与未处理(抵押"买卖不破租赁")；依据年份矛盾。**务必核测算表再定性；可借助待估宗地自身历史出让成交价做合理性印证。**
