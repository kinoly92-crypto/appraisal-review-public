# 资产评估报告 审核要点（条款级，依据《中国资产评估准则汇编2026·第八版》全文通读）

> 说明：本文件依据《中国资产评估准则汇编2026（第八版）》**全文通读**整理（基本准则+全部执业准则+全部专业准则+全部指南+全部指导意见，并参照专家指引）。准则为审核核心，公开网络资源为补充，随审核迭代优化。

## 报告类型特征
- 资产评估项目通常含「资产评估报告」+「资产评估说明」+「评估明细表」+「测算表」(+委托合同/权属证/底稿)。
- **评估说明也是待批准交付文档，必须审核**；其意见与报告意见**合并在同一份审核意见 doc**(用「位置」字段区分来源)。
- **批注版出两份**：资产评估报告、评估说明各一份(Word真批注)。测算表/明细表是Excel，意见进审核意见。
- 子类型：固定资产(机器设备/房屋建筑物)、无形资产(含土地使用权/专利/商标/著作权/知识产权/数据资产)、企业价值、不动产、房地产年租金、森林资源、珠宝首饰、金融不良资产(债权)等。
- 目的子类：转让/出资/抵质押/并购重组/财务报告/涉税/诉讼仲裁/司法处置/破产清算等——目的不同，准则/指导意见与披露要求不同。

## 一、准则体系全景（效力层级：法>准则>指南/指导意见>专家指引）

**2. 执业准则(7项,通用)**：资产评估报告 / 资产评估程序 / 资产评估委托合同 / 资产评估档案 / 利用专家工作及相关报告 / 资产评估方法 / 职业道德准则。
**3. 专业准则(7项,按资产类)**：企业价值 / 不动产 / 机器设备 / 无形资产 / 森林资源资产 / 珠宝首饰 / 知识产权(指南)。
**4. 指南(5项)**：知识产权资产评估指南 / 资产评估机构业务质量控制指南 / 企业国有资产评估报告指南 / 金融企业国有资产评估报告指南 / 以财务报告为目的的评估指南。
**5. 指导意见(15项)**：价值类型 / 法律权属 / 投资性房地产 / 专利 / 商标 / 著作权 / 文化企业无形资产 / 金融不良资产 / 实物期权 / 人民法院委托司法执行财产处置 / 珠宝首饰评估程序 / 企业并购投资价值(2021) / 体育无形资产(2022) / 数据资产(2023) / 关键核心技术(2026)。

## 一B、⭐2027年新《资产评估执业准则——资产评估程序》（评估基准日 ≥ 2027-01-01 的报告适用）
> 依据：《资产评估执业准则——资产评估程序》（新版，2027-01-01 施行）+ 官方新旧核心变化逐条对照表。原文见桌面《资产评估执业准则-资产评估程序.pdf》《资产评估程序新旧准则对照表.pdf》。

**版本切换（按评估基准日判定，审核第一步先看基准日）**
- 新《资产评估程序》准则自 **2027年1月1日施行**，**废止中评协〔2018〕36号**（2018-10-29 发布的旧版）。
- **凡评估基准日在 2027-01-01 及以后的资产评估项目，一律按新准则审核**；基准日在 2027 年之前的，仍按旧版（36号）。**基准日跨在临界点时以报告载明的基准日为准。**
- 适用面：本准则为**通用执业准则**，凡按资产评估准则体系执业的项目均适用——资产评估各子类、**企业价值、矿业权评估**（矿业权亦在资产评估准则体系内，见 `mining-rights.md`）等。房地产估价/土地估价另有本行业规程体系，其程序要求可参照本准则精神但以各自规程为准。

**核心修订逻辑**：从旧版"流程清单式"转向"**精细化质控 ＋ 实质风险管控 ＋ 新技术/保密适配**"，把内部审核、业务报备、涉密合规、替代程序披露、无法判断影响禁出报告等实务痛点写入**强制要求**，全面抬高执业留痕与责任追溯标准。**逐条审核抓手（共17处变化）：**

1. **⭐基本程序 8项→9项（第5条）**：新增 **①内部审核形成评估结论、②编制正式报告并完成业务报备后出具** 为**独立强制程序**（旧版并入"编制出具报告"一项）。完整9步：明确业务基本事项→订立委托合同→编制评估计划→现场调查→收集整理资料并核查验证→**评定估算并编制初步报告**→**内部审核形成评估结论**→**编制正式报告+完成业务报备+出具报告**→整理归集档案。**抓手**：底稿须体现内部（分级）审核、业务报备两环节的独立留痕，缺任一环即程序缺失。（注：与《基本准则》第8条"8项"表述不再同步，2027起程序层以本准则9项为准。）
2. **⭐程序受限收紧（第6条）**：无法完全履职、经弥补后**未对结论产生重大影响**方可继续，且须**在报告披露**、在**底稿记录"限制情形＋已采取弥补措施＋程序缺失影响分析"三要素**；**新增"或者无法判断其影响程度的，不得出具报告"**——堵住"说不清影响却照出报告"的模糊地带。**抓手**：程序受限项三要素是否齐全留痕并披露；影响不明仍出报告＝硬伤。
3. **工作底稿（第7条）**：改为"应当**完整、有效**记录"程序履行情况（旧仅"记录"）。**抓手**：留痕的完整性与有效性。
4. **承接前基本事项（第8条）**：术语"受理"→"**承接**"；第(六)项删去"需要批准的"限定，改为"资产评估项目涉及的**经济行为的审批情况**"——**审批核查范围扩大到全部经济行为，不再限于"需审批的"**；10项基本事项明确含评估服务费及支付方式、工作配合协助事项。
5. **风险评价前置（第9条）**：对专业胜任能力/独立性/业务风险须**综合分析和评价并形成书面记录**，不满足**不得承接**。**抓手**：承接阶段有无书面风险评价留痕。
6. **评估服务费（第10条·新增）**：机构应按**工作量、所需资源投入等因素合理确定评估服务费**——回应低价竞争治理。
7. **评估计划动态调整（第11条）**：计划与实际实施有重大差异的，应**及时调整尚未执行部分**的计划。
8. **抽样现场调查（第12条）**：采用抽样的，须对**抽样方法、抽样比例、样本代表性**分析说明、确保抽样有效性（防形式化抽样）。
9. **资料收集（第13条）**：明确资料涉**财务/经营/法律/产权/技术/市场/环境**多维度；**新增涉密项目须配备保密人员、必要时用专用保密设备、设独立保密场所**。
10. **资料确认被拒（第14条）**：相关人员**拒绝确认**明细表/重要资料的，按第6条（告知限制与风险＋记录＋弥补）处理——填补旧版空白。
11. **专家意见独立性（第16条）**：超出专业能力的核查验证事项，委托其他机构/专家出具**独立意见**；无法核查验证事项须底稿说明并报告披露，重大影响或影响不明不得出报告。
12. **⭐评估假设独立成条（第20条·新增）**：应**合理使用评估假设，并在报告披露评估假设**——假设的使用与披露上升为独立强制条款。**抓手**：报告是否披露全部关键假设、假设是否合理。
13. **内部审核分级化（第23条）**：按法律法规/准则/机构内部质控制度对报告**分级审核**，并对**审核过程和结果详细记录**——固化三级复核＋全过程留痕。
14. **沟通后调整须复核（第24条）**：出报告前可与委托人（或其同意的当事人）沟通，**若据此调整报告，须对调整后报告再次审核**（防沟通妥协降质）。
15. **特别事项充分披露（第25条·强化）**：对结论有重大影响的特别事项须予关注并**在报告充分披露**。
16. **⭐业务报备为法定前置（第26条）**：编制正式报告后**须先完成资产评估业务报备，再向委托人出具报告**；**出具报告须与报备系统内报告保持一致**。**抓手**：报备先于出具、纸质报告与报备内容一致。
17. **档案时效＋涉密（第27条）**：应"**及时**"整理归档；涉密档案须同时满足《保守国家秘密法》。

> 下文 §二模块7、§五、§七等处凡引"程序准则"，**基准日 ≥ 2027-01-01 者一律以本节新条款号/新要求为准**（尤以 8项→9项、无法判断影响禁出报告、业务报备前置三点为高频抓手）。

## 二、通用层审核 7 模块（挂条款）
1. **形式要件**：标题及文号、目录、声明、摘要、正文、附件齐全（**报告准则第11条**；正文14项见**第14条**/基本准则第22条）。标题"企业名称+经济行为关键词+评估对象+资产评估报告"，文号"机构特征字+种类+年份+序号"（报告准则附2/国资指南第7条）。**※审核在出报告前进行，报告文号此时尚未生成——"缺文号/无文号"不作为问题提出，只核标题/目录/声明/摘要/正文/附件等其余形式要件（见 SKILL.md 一节）。**绪言格式见国资指南第12条。签字盖章规则（**报告准则第8条/基本准则第29条**；珠宝须资产评估师(珠宝)）：**应由至少两名承办专业人员签名+机构印章，法定业务须至少两名资产评估师签名**——**此为"应当如何签章"的资格/一致性要求，须核署名人是否符合且与执业登记一致；但签字盖章本身在审核通过、报告出具时才完成，"缺签字/缺机构章/未盖章"不作为问题提出（见 SKILL.md 一节）。**
2. **声明事项**：声明7项（**报告准则第12条**/国资指南第9条）——依据准则编制、使用范围、不等同可实现价格、关注假设/特别事项、独立客观公正担责、利益关系声明、现场调查与权属查验声明等。
3. **报告要素完整性**（**报告准则第14条**正文14项）：委托人及使用人/评估目的(**第16条目的唯一**)/对象与范围(**第17条**)/价值类型(**第18条**理由+定义)/基准日(**第19条**)/依据(**第20条**:法律法规+准则+权属+取价)/方法(**第21条**及理由,仅选一种须披露)/程序实施(**第22条**)/假设(**第23条**)/结论(**第24条**文字+数字+有效期,通常确定值,经沟通可区间值)/特别事项/使用限制(**第26条**)/报告日(**第27条**)/签名印章。
4. **关键日期勾稽**：基准日与委托合同一致(**第19条**)；**基准日距经济行为实现日≤1年才可使用报告**(**第10条**)；报告日通常为结论形成日、可不同于签署日(**第27条**)；关注**重大期后事项**(基准日↔报告日之间)。
5. **数据与文字勾稽**：陈述清晰准确、**不得误导**(**第4条**)；摘要与正文一致；**报告↔说明↔明细表↔测算表多方数据一致**(建成年月/面积/单价/金额/币种汇率)；资料核查验证(**程序准则第15-16条**/专家指引第8号:观察·询问·书面审查·实地调查·查询·函证·复核)；大小写/单位/错别字。
6. **披露充分性**（**报告准则第25条**特别事项）：①权属资料不完整/瑕疵 ②委托人未提供的关键资料 ③未决事项/法律纠纷 ④重要利用专家工作 ⑤**重大期后事项** ⑥程序受限及弥补措施与影响 ⑦其他。权属瑕疵须描述并披露（法律权属指导意见第9条）；无法核查验证事项须披露影响、重大影响则不得出报告(程序准则第16条)。
7. **内部程序合规**：基本程序不得随意减少(**基本准则第8条/程序准则第5条**；旧版8项，**基准日≥2027 按新程序准则第5条为9项**，新增内部审核、业务报备为独立强制程序，见 §一B)；**承接**前明确基本事项含**经济行为审批情况**(程序准则第8条；新版审批核查范围含全部经济行为)；初步报告须**内部审核**后出具(基本准则第18条/程序准则第23条；新版为分级审核+过程结果详细记录)；**⭐基准日≥2027 者：正式报告须先完成业务报备再出具、且与报备系统一致(新程序准则第26条)；程序受限无法判断影响程度的不得出报告(新第6条)**；签章如上；**档案保存≥15年、法定≥30年**(基本准则第32条/档案准则第17条；报告日后90日内归档,重大项目结论有效期届满后30日内)；独立性/利益关系回避(职业道德准则第11-13条)；保密(第18条)；国有资产涉备案/核准/进场交易。

## 三、方法选用审核（方法准则）
- 三基本方法=市场法/收益法/成本法及衍生(**基本准则第16条/方法准则第2条**)；前提与可靠性因素(市场法第5-8条、收益法第10-14条、成本法第15-20条;成本法不适用情形第17条)。
- **满足多方法条件时应选≥2种**综合分析(**方法准则第22条**)；**可只用一种**仅限三情形(法规规定/仅满足一种适用条件/行业普遍无法排除的操作条件限制)(**第23条**)；**只选一种须披露其他基本方法不适用原因**(**第24条**)；多方法须对测算结果分析比较(程序准则第21条)。
- **收益法折现率审核**(专家指引第12号)：CAPM `Re=Rf+β(Rm-Rf)+ε`、WACC；无风险利率=剩余10年期及以上国债到期收益率；市场风险溢价=沪深300等历史超额收益(≥10年,周/月数据);β由可比上市公司去杠杆/加杠杆调整(资本结构取市场价值);特定风险报酬率(规模溢价+其他);债权报酬率以LPR为基础;**折现率口径必须与预期收益口径一致**;报告须披露模型、参数确定方法与数据来源(可追溯)。

## 四、价值类型审核（价值类型指导意见）
- 市场价值定义(**第4条**) + 市场价值以外(**投资价值/在用价值/清算价值/残余价值**第5-9条)；**抵(质)押**目的按担保法及金融监管选价值类型(**第21条**)，税收/保险/财报目的分别按相应法规会计准则(第22-24条)；报告须披露价值类型及定义(**第25条/报告准则第18条**)；价值类型须与评估假设相关(第14条)。
- **⭐租金评估价值类型径称"市场价值"，不写"市场价值（年租金）"**：年租金评估的价值类型就是**市场价值**(价值类型为法定的有限种类，"年租金"不是价值类型)；"年租金/租期1年/年付/含增值税/房地合一"等属**价值内涵**，应在价值类型定义之后、以"本项目中市场价值内涵为年租金……"的形式表述，**不得把"（年租金）"缀在价值类型名称后**。审核核：摘要/价值类型章/特别事项处"价值类型"一栏统一写"市场价值"；内涵单独叙明且前后一致。依据价值类型指导意见第4/25条、报告准则第18条。

## 四B、⭐追溯性评估：新旧规范适用（价值时点明显早于报告出具日的项目必查）
**触发**：已灭失/受损财产索赔、追溯损失评估、历史时点重估、司法追溯定价、以往年度国资处置补评等——凡**价值时点/评估基准日明显早于报告出具日**者。

**基本原则＝实体从旧、程序从新。** 依据来源：最高人民法院《关于审理行政案件适用法律规范问题的座谈会纪要》第三部分"关于新旧法律规范的适用规则"——"根据行政审判中的普遍认识和做法，行政相对人的行为发生在新法施行以前，具体行政行为作出在新法施行以后，人民法院审查具体行政行为的合法性时，**实体问题适用旧法规定，程序问题适用新法规定**。"

映射到评估业务：

| | 对应内容 | 适用哪一版 |
|---|---|---|
| **实体** | 具体测算过程中**影响评估结论的取价依据**：价格、参数、指数、税率、补偿标准、市场数据及对数据的分析 | **价值时点当时有效** |
| **程序** | **报告出具日规范评估活动的有效准则**：评估准则、执业规范、报告体例、程序要求、披露要求 | **报告出具日现行有效** |

**一句话**：执行追溯性评估业务时，只是在追溯的基础上考虑**价值时点有效的数据及对数据的分析**，而**不是执行当时有效的评估准则**。

**审核抓手**：
- ①**两头混用**是最常见错误：拿价值时点当年的旧版评估准则套报告体例（错，程序应从新）；或拿报告日的现价、现行税率去测追溯价值（错，实体应从旧）。
- ②**取价依据须表征价值时点**：询价记录、可比案例、价格指数、补偿标准的**时点必须落在价值时点**，不得用报告日询价充当（另见 §八 追溯索赔项目的询价时点抓手）。
- ③**"评估依据"章节须分层**：准则类依据＝出具日现行有效版本（如基准日≥2027-01-01 另按 §一B 新版程序准则）；取价类/政策标准类依据＝价值时点有效版本。**两类不可一锅烩**，报告若把二者混在同一清单且版本互相矛盾，按技术问题提出。
- ④报告若自行论述新旧适用且与上述原则相悖，或对"为何用某一版准则/某一时点数据"未作说明，按披露不充分提出。
- ⑤价值时点与报告日间隔越长，越须核**期间市场变化的处理与披露**，以及评估假设是否覆盖追溯期内的状态变化。

## 五、法律权属审核（法律权属指导意见 + 核查验证专家指引第8号）
- 权属对结论有重大影响、应关注并恰当披露(**第4条**)；估价师**不对法律权属提供保证**(**第5条**)；权属不清/瑕疵/不完备应特别关注、要求承诺函或说明函、考虑是否受理(**第6条**)；提供虚假或拒不提供可拒绝(**第7条**)；**核查验证**(核对原件与复印件、公开渠道查询、产权登记现场查询)并披露(**第8条**)；报告描述权属、披露瑕疵(**第9条**)。
- **民法典担保物权要点(抵押类资产/优先受偿审核通用)**：不动产抵押自**登记**时设立(民法典402，未登记不享优先受偿)；抵押前已出租转移占有的原租赁不受影响(405·买卖不破租赁)；同一财产多抵押清偿顺序按登记时间先后、已登记先于未登记、未登记按债权比例(414)；抵押权须在主债权诉讼时效内行使(419)；应收账款/股权/知识产权出质须登记设立(440-445)；普通诉讼时效3年(188)。详见 `debt-analysis.md §九`。上位法：《资产评估法》(评估机构/人员/准则/法律责任，签署虚假或重大遗漏报告的责任)。
- **各类权属证明资料核查清单**(专家指引第8号)：不动产→不动产权证/土地证/房产证(未办证查取得文件并披露);森林→不动产权证/林权证;矿业权→采矿/勘查许可证+出让转让合同+付款凭证;机器设备→机动车登记证/船舶证书/购置合同发票报关单/融资租赁合同;知识产权→专利证书+登记簿副本+年费凭证/商标注册证/著作权登记证(可与官方网站公示核对);财务信息→审计报告(查事务所资质独立性)/未审财务(趋势与账簿核对、抽样凭证);担保→征信系统查询;诉讼仲裁→声明书+公告核对;抵质押→合同+主债权合同。市场资料：权威平台可直接引用但关注时效;浏览量少网站需≥2来源相互验证。

## 六、专业准则审核层（按子类，挂条款）

- **第1-5号(金融企业专题)**：①金融监管指标(银行流动性/不良率/拨备/资本充足率/存款准备金;证券净资本;保险偿付能力充足率;信托净资本)——评估须使预测达标、不达标披露风险;②金融IPO(对象=股东全部权益、市场价值非内在价值、目的≠定价≠发行底价、募集资金处理);③④金融收益法FCFE/FCFF+市场法统计模型(PE/PB);⑤寿险(内含价值法、新业务价值、折现率口径)。
- **第13号 境外并购**：政治/法律/财务/金融/整合五类风险;三阶段(境内准备/境外核查/境内后期);外语翻译人员管理;会计准则差异调整;外币按中间价折人民币;计量单位/纪年换算;引用境外专业报告要件。
- **第15号 知识产权侵权损害(法院委托)**：三路径=权利人实际损失/侵权人获利/合理许可费;损失收益=未侵权预计-侵权后实际(替代法/趋势法/比较法);侵权获利按营业利润(完全以侵权为业按销售利润);合理许可费用可比参照法;考虑货币时间价值。
- **第16号 计算机软件著作权**：登记**仅形式审查**,登记证书不完全代表权属稳定,须补充底稿/合同核查权属;成本法(COCOMO模型估编码成本、直接+间接+利润+税费);收益法(增量/节省许可费/超额收益);市场法可比案例**通常≥3**;区分自行修改/受让许可部分、版本升级是否构成新资产。
- **第9号 数据资产**(与数据资产指导意见重合,见§六)、**第10号 疫情期间程序**(程序受限弥补措施与披露,常态化参照)。

## 七C、国资监管合规 + 重大遗漏判定 + 质量评价（补充依据·桌面"补充-资产评估项目审核参考依据"文件夹）
> 国企评估项目除准则外，须叠加国资监管合规审核；并以"重大遗漏判定"框架给审核意见定级。

**A. 国资评估监管合规（核准/备案/交易/审计前置）**
- **核准 vs 备案**：国资评估项目实行核准制或备案制(国资委令12号《企业国有资产评估管理暂行办法》)；央企核准/备案工作指引(国资发产权71号/64号)；云南省属企业评估管理/核准/备案(云国资产权2018·147/148/149号)。**云南：企业价值评估须做审计(147号)、备案要求无保留意见标准审计报告(149号)**。
- **专家评审(云国资产权2023·90号)**：核准项目/省国资委备案项目/上市公司重大资产重组/经济行为涉非国有单位/增减值幅度较大/涉境外项目等须开**专家评审会**(审计/资产评估/房地产/土地/矿业权/法律专家，资产评估专家≥2人)；评审重点=核准备案合规性/评估范围完整规范/基准日合理/依据假设方法模型参数预测数据结果合理/特别事项及期后事项披露；评审结论"通过/修改完善后通过/不予通过"，二次评审为终审、再不过换机构重评。专家意见为参考、不替代核准备案单位审核、不减评估机构责任。
- **进场交易**：国有资产交易监管(国资委令32号)、交易流转(国资发产权规2022·39号)、上市公司国有股权(令36号)；增资扩股/股权转让须进产权交易所、以评估结果为定价参考。
- **⭐2024优化(国资发产权规2024·8号·最新)**：①**8种可不评估情形**(无偿划转/对国独全资增减资/国独国全资企业间交易/同比例增减资/有限责任↔股份变更持股比例不变/同一控制母子或全资子间交易/解散注销无债务/挂牌转让无法获资料参股股权及账面原值≤500万存货固资或可获公开市价房产)；②**5种可估值(非评估)情形**(境外/并购上市公司/原创前沿涉密卡脖子关键核心技术战新企业/管理基金对外投资转让/有限合伙份额)；③**作价红线：对外转让价<评估结果90% 或 对外收购价>评估结果110%，须经济行为批准单位论证并书面同意**；估值区间则价格须在区间内；④知识产权/科技成果/数据资产可咨询≥3家后挂牌/拍卖/询价/协议定价。
- **商誉(国资发财评规2022·41号)**：央企商誉管理，关注商誉减值；并购重组重点。
- **行政事业单位**：中央行政事业单位国有资产使用管理办法(出租出借/对外投资/担保的评估与审批)。
- 关联法规：**《中华人民共和国公司法》(2023-12-29 第二次修订，2024-07-01 施行)**——企业价值/股权类项目的上位法依据，审核时重点对照：①**注册资本限期认缴**(有限责任公司股东自成立起**5年内**缴足认缴出资额，第47条；存量公司过渡调整)；②**非货币财产出资须评估作价**、不得高估低估(第48条)，与评估目的"出资/增资"勾稽；③减资(第224-226条·须编资产负债表及财产清单/通知债权人)、利润分配、股权转让(第84条·其他股东优先购买权)、异议股东回购、清算(第229条起)等情形是否与评估对象界定/价值类型/特别事项一致；④股东出资不实/抽逃出资的责任(第49、53条)。具体条文以现行有效文本为准、按需核对最新修正。配套：公司法注册资本登记管理(国务院令2024·784号，非货币出资须评估)。民法典(债权/物权/合同，引用法条以现行为准)。

**B. ⭐重大遗漏判定框架（北京评协惩戒委2024课题·定级抓手）**
判定依据=资产评估准则(基本/职业道德/执业准则)。**"重大遗漏报告"=因过失对应当考虑的重要事项遗漏致报告不实**。**5方面判定标准**：①**评估结果存在重大差错**(纯计算/电子表格链接/折现时点错误、公式漏多项、漏重评资产负债、漏重计税费等——**无需专业判断即可算出正确结果、影响评估值≥20%**)；②**评估结论存在重大不确定性**(确认有错但需进一步专业判断/无法准确算出正确值：估值乘数选错、应计未计资本性支出、溢余现金未加回、非经营资产负债漏计、应评未评长投/无形/表外资产、税率税基优惠错、收入费用预测漏计、应修正未修正、**参数与结果矛盾/说明↔计算表↔底稿不符/收益法↔资产基础法数据不符**、可比案例不可比)；③评估结论合理性存在重大疑问；④**履行评估程序存在重大缺失致结论重大不确定**(程序缺失一般由结果错误倒推、不单独提)；⑤**关键和重大评估假设不合理致合理性重大疑问**。**20%是"重大"低线，20%以下属非重大**。
- **审核意见定级直接套用**：可核实计算错误且影响≥20%→重大差错(重大问题)；确认有错但算不出正确值→重大不确定性(重大问题)；披露应披露能披露但未披露的重大影响信息→重大遗漏。认定须专家论证+复核。

**C. 评估机构执业质量评价（8号文附件1·央企备案后评价·亦可作报告质量自查表）**
服务质量20分(团队/态度/方案/核查尽责/及时性/审核意见答复) + 报告质量80分：报告完整性22分(报告+说明+明细表+利用专业报告齐全、收益法预测表完整、签章附件齐全) + **评估说明完整性45分(资产基础法20[按资产分类介绍方法参数结果、重要资产有案例且与取价依据匹配计算无误、账外无形资产纳入、不简单按账面值确认]/收益法20[行业经营收益分析、收益模型与期限、折现率过程依据、收入成本费用折旧摊销营运资金资本性支出所得税预测、非经营性资产负债溢余资产界定]/市场法20[可比性、数据分析调整、价值比率、流动性折扣、多比率]/整体5)** + 报告修改13分(因机构原因3次以上修改才符合备案=0分；**评估结果调整>10%=0分**)。

**D. 参考文件（背景/案例，按需查阅，非逐条规则）**：上市公司并购重组典型案例汇编、国有企业相关法律法规汇编、资产评估协会评估技术案例汇编、关键核心技术资产评估指导意见(已并入§六)、增值税法实施条例、民法典。

## 七D、执业质量与内部治理自查（《资产评估法》全文 + 2025自查指导手册，已全文精读）
> 两份均为资产评估项目审核依据。《资产评估法》是上位法红线；《2025自查指导手册》是中评协把行业检查/自律检查要点+处罚监管自律案例结集的"自查依据与整改方向"，给底稿/报告/说明审核提供逐条核对清单与高频问题库。

**A. 《资产评估法》(2016-12-1施行) 审核红线条款**
- **法定评估(第3条)**：涉国有资产或公共利益等、法律行政法规规定须评估的，应当依法委托评估；应评未评的，责令改正、拒不改正处**10万~50万元罚款**(第51条)；委托人未依法选机构/串通唆使出虚假报告/不如实提供资料/超范围使用报告同罚(第52条)。
- **承办与签章规则**：受理业务应指定**至少两名评估专业人员承办**(第24条)；报告由**至少两名承办的评估专业人员签名+机构盖章**(第27条)；**法定评估须至少两名相应专业类别的评估师签名+盖章**(第28条)。**※承办人数/专业类别的资格要求须照核；但签名盖章在审核通过、报告出具时才完成，"缺签名/缺盖章"不作为问题提出（见 SKILL.md 一节）。**
- **程序(第25/26条)**：现场调查+核查验证；除准则只能选一种外应选**两种以上方法**综合分析；机构应**内部审核**。
- **档案(第29条)**：保存**≥15年，法定评估≥30年**。
- **使用限制(第32条)**：按法律规定和报告载明范围使用，违规使用机构与人员不担责。
- **禁止行为**：人员不得签本人未承办的报告、**不得签虚假或有重大遗漏的报告**(第14条)；机构不得受理与自身有利害关系业务、**不得分别接受利益冲突双方委托对同一对象评估**、不得出虚假或重大遗漏报告(第20条)。虚假报告：机构停业6月~1年(第48条)、人员停止从业2~5年(第45条，情节严重5~10年终身禁业)。
- 评估定义(第2条·不动产/动产/无形资产/企业价值/资产损失或其他经济权益)；独立客观公正(第4条)；人员只能在一个机构执业(第5条)。

**B. 机构内部治理与质量控制自查(自查手册第二章)**
- **内部治理7方面**：内部管理制度建设(业务/档案/人事/继续教育/财务/报备制度)、治理结构(实际控制人须为股东/合伙人)、持续满足设立条件(合伙≥2名评估师且2/3合伙人三年经历；公司≥8名评估师+≥2股东)、分支机构统一管理、**评估师管理(禁挂靠)**、财务管理、业务报备(全部报告向中评协备案，回执不作认证/免责依据)、证券业务备案。
- **质控体系8方面**：质量控制责任(最高管理层终责/首席评估师/项目负责人[法定评估项目负责人须为评估师]/项目审核人员/团队成员)、职业道德、人力资源、业务受理(按风险分类管理)、业务计划、业务实施与报告出具、监控改进、文件记录。**内部审核目标=未经审核合格不进入下一程序；重大分歧未解决不得出报告**。
- **风险防范**：按业务收入**≥5%**计提职业风险基金或买职业责任保险(累计赔偿限额≥已保年度业务收入5%)；证券业务机构净资产**≥200万**；项目期间及完成后规定期限内不得持有/买卖相关上市公司股票。

**C. 八大程序底稿自查要点(自查手册第三章·通用)**
业务承接(基本事项+**专业能力/独立性/业务风险/利用专家/综合评价均须签字审批**)→委托合同(11项基本内容)→评估计划→**现场调查**(询问/访谈/核对/监盘/勘查；函证回函地址须为评估机构、回函差异须追加程序、未回函须替代程序并记录)→**收集资料**(权属/历史沿革/财务经营/经营计划与收益预测/权属证明/以往评估交易/宏观行业/可比企业/经济行为文件/申报明细表[提供方盖章])→评定估算→内部复核(复核意见+项目组答复+签名日期)→档案归集(管理类+操作类底稿、报告与合同须纸质)。

**D. 四类业务高频问题库(自查手册各章"常见问题"·审核重点扫)**
- **企业价值/收益法**：非经营性资产/负债/溢余资产识别有误；收入增长率远高于行业未做合理性分析；主要参数取值无支撑(如前三季均值作第四季)；**营运资金公式错误(正确=最低货币资金+应收账款+存货−应付账款；非整年第一期追加额=整年营运资金−基准日营运资金)**；折旧摊销与明细表不一致；**所得税未弥补亏损/未加计扣除**；折现率Beta剔除财务杠杆未考虑所得税；折现期限(年中折现)计算错误；市场法可比性与口径不一致；资产基础法漏识表外商标/著作权/专利。报告：评估目的与经济行为/合同不一致；依据失效或缺(如国资股权转让缺交易监管办法)；方法选用与测算不一致；**有限期经营企业(风电/光伏)却用持续经营假设、现金流均匀流入却用年末折现**；特别事项/附件不全；账面与评估差异大未说明。
- **财报目的**：价值类型=**可收回金额(公允价值减处置费用净额 与 未来现金流现值 孰高)/公允价值/可变现净值**；基准日可为资产负债表日/购买日/减值测试日；商誉资产组范围与账面公允价值(漏归属少数股东商誉、混入非经营资产/付息负债、扩大资产组)；可收回金额确定基础与账面基础须一致；**现金流不含筹资活动与所得税**；连续财报目的方法与关键参数须前后一致；投资性房地产公允价值结论通常含土地使用权(核算不含则扣除披露)。
- **无形资产**：分成率确定缺分析依据、许可费收入与产品经营收入用同一分成率；收益口径与折现率口径不一致、不同无形资产(商标vs专利)未区分折现率；收益期与生命周期不匹配。专利(年费凭证、经济/功能贬值、剔除无关收益)；著作权(衍生收益、软件代码数量/单行成本合理性)；商标(可续展不应与有限寿命资产打包、收益期、折现率有别于企业)。
- **单项资产**：权属瑕疵未取得说明/承诺；现场勘察代表性不足/缺勘察照片；重置成本取价(设备购置/建安直接费)取费(安装/运输/前期费)依据不充分；主要设备无询价记录；**交易案例可比性弱(实物权益不相关/成交日远/类型不符/非成交价未修正为正常价格)**；关键假设脱离现实无合理解释。
- 案例印证(财政部/证监会处罚多因)：参数计算错误致**高估**(营运资金漏出口退税、折旧摊销现金流与利润表不一致、土地容积率修正系数错)、访谈走访结论无客观依据构成**虚假记载**、商誉减值收入/毛利率/研发费预测依据不足。多数差错方向是**高估**——审核尤其警惕高估。

## 八、实战常见问题（来自真实审核，迭代积累）
**⭐申报表/明细表列错位（逐表逐列常识体检必查）**:多张明细表的**列顺序可能不一致**，若数据按其中一张的取值顺序填入另一张，会导致**整列错位串列**。典型:某项目「评估申报明细表」表头为…房间名称│竣工日期│楼层│结构，而「评估明细表」为…房间名称│楼层│竣工日期│结构，数据按后者顺序填入前者→"竣工日期"列显示"一层"、**"楼层"列显示日期序列号 44370/45119/37852…(即 2021-06-23/2023-07-12/2003-08-19)**，"楼层=44370层"明显违背常识。审核须对**每张可见 sheet 每一列**跑常识/量纲检查(楼层=个位数、竣工日期=日期、面积/年限在合理量级)，并**同一字段跨表对齐**;裸序列号、错列、缺位即为问题。
报告↔说明↔明细表多方数据不一致(建成年月/面积口径/大写金额与底稿差额);测算底稿模板残留(混入住宅/车间/**他项目整表**[如某项目测算表/明细表Sheet1整表为"云南农业大学"残留]、#REF!断链、坐落0；**且残留参数可窜入报告正文**——如残留项目基准日2026-04-17窜成报告有效期"2027-04-17"与正确截止日2027-05-11矛盾);
**⭐房产出租/租金面积内涵须明确（无权证尤须）**:报告应说明面积内涵口径=**建筑面积/套内建筑面积/套内使用面积/其他**及确定依据(权证/测绘报告/检测鉴定报告/申报);无权证无测绘时仅写"建筑面积"不交代来源口径不充分;**评估对象与可比实例面积口径须一致**(否则单价×面积测算失真)。依据报告准则第十七条、不动产准则、法律权属指导意见第八条。
**⭐房地合一租金（评估目的为租赁不动产时必查）**:不动产租金须体现**房地合一**——租金内涵明确为"房屋及其分摊土地使用权"合一,或**分别测算房屋租金+土地租金后汇总**;**不得只计房屋租金而漏计土地租金**(否则低估);**房地一体不可分开租给不同承租人**,报告口径须一致。核:租金内涵是否声明含地、可比实例是否同口径、分算是否汇总完整。依据不动产准则第二十三条(土地与建筑物避免重复或漏算)、报告准则第十八条。全文名称/称谓一致性;国资备案/核准/进场交易+签字人资质;不动产权属披露(是否取得证、出让/划拨、房地合一租金涉土地租金);期后事项(发证日早于报告日须披露,结论仍以基准日为准);方法适用性论证自洽、仅一种方法须披露原因(方法准则第24条);可比实例期日修正;成本逼近法参数依据;取价依据底稿留痕;收益法折现率口径与收益口径一致、参数来源可追溯(专家指引第12号)。**务必核测算表/明细表再定性**(曾因报告文字笔误差点误判,核测算表后发现实际无误)。

**⭐分项/分层评估必须逐项测算，不得只测一项其余硬填**（2025某项目 广福城A10栋2、3层年租金）：评估范围含多项(多楼层/多单元)时，评估说明须对**每一项**列示可比实例、比较因素、修正系数与比较价格。教训：该项目评估说明只测算了二层(253.49㎡)，占评估值 **81.45%** 的三层(1,176.61㎡、年租金851,100元)**无任何评定估算过程**，明细表三层单价 60.279651432 元/㎡·月 系**手工硬填(单元格无公式)**，且不符合说明自设楼层修正规则(每层±1%→应63.06、年租金890,400，差39,300元)。**抓手**：①明细表单价列逐格看**是否为公式**、小数位是否异常(12位小数=倒算或硬填)；②用说明自设的修正规则反算，核对与填列值是否一致；③按占评估值比重排序，比重大的项目反而无测算＝重大不确定性。
**⭐比较因素条件表须与报告/说明的区位·实物描述逐项交叉核对**：同一份说明常出现"区位状况"文字描述与"比较因素条件说明表"对评估对象的取值矛盾(如文字"基础设施达到六通/交通较便利" vs 表内"五通/交通便利")，且**指数表对该因素一律取100不修正**——两种情形必有一错，且方向多为**抬高**评估对象条件、减少下修，直接影响比较价格。核法：把说明所列各因素**等级划分与每级修正幅度**抄出来，用评估对象与实例的条件描述**反推应有指数**，与指数表逐格比对。
**⭐《国有资产评估项目备案表》也是待批准交付文档，须一并审核**（审核意见单列"国有资产评估项目备案表："大类）。高频错：①"产权持有单位(盖章)"误填**委托方**(与表内"产权持有单位"栏自相矛盾)；②企业名称变更后备案表仍填**变更前名称**；③"评估机构名称"与营业执照/报告不一致；④"资质证书编号"栏错填财政部门**备案公告文号**且年份过期；⑤经济行为类型**重复勾选**且与报告所述承租/受让对象性质矛盾(如勾"租赁给非国有单位"而报告写"出租给集团作职工食堂")；⑥**年租金评估值误填入"投资性房地产—评估价值"栏**与账面价值并列，形成"减值94%"的误导对比("增减值/增减率"空白)——年租金应只填"年租金"栏；⑦评估对象表述未体现"年租金"内涵。
**⭐税法依据时效(2026年起必查)**：**《中华人民共和国增值税法》2024-12-25 通过、2026-01-01 施行，《增值税暂行条例》同时废止**；《增值税法实施条例》＝**国务院令第826号**(2026-01-01 施行)。不动产租赁服务税率仍为 **9%**。故 2026 年起出具的报告若仍把"《增值税暂行条例》(国务院538号令)+财税〔2016〕36号"列为评估依据＝依据失效(税率本身可能没错，要分开说)。
